### Configuration layers
1. `.env`: machine paths, ports, model tags (rarely changes).
2. `settings` table: user preferences changed in the UI (voice, silence timeout, transcript visibility, retention).
3. Code constants: rubric definitions and prompt versions (version-controlled so scores can be traced).

### Data directory (`DATA_DIR`, default `~/.local/share/ai-interview-coach/`)
```
coach.db  coach.db-wal  backups/  exports/  logs/  audio/ (only if retention enabled)
```
